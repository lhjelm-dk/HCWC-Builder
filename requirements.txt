# What the app needs to run. Nothing here is optional. This is the canonical list: the
# deployment installs it, and pyproject.toml mirrors it (tests/test_ui_imports.py checks).
# The paper scripts also need matplotlib (pyproject's dev extra).
#
# **Floors, not pins**, matching WellVolPOS and E-POS: the test suite guards against
# drift, while pinned versions break installation wherever no matching wheel exists.
# These floors imply Python 3.11+; numpy 2.1 and scipy 1.14 publish no wheels for 3.9.
# On Streamlit Community Cloud set the Python version under *Advanced settings* when
# you create the app -- it cannot be changed afterwards.
numpy>=2.1
pandas>=2.2
scipy>=1.14
plotly>=5.24
# 1.56 is the floor because `st.iframe` first appears there; it replaces
# `st.components.v1.html`, whose stated removal date has already passed.
# A ceiling, against the rule above, from 30 Sep 2026: `SafeSessionState.filtered_state`
# is gone by 1.64, and `hcwc/io/prospect.py` reads it to save a prospect while seven tests
# read it to check the round trip. 1.62 is the newest version the suite is known to pass
# on. Raise the ceiling with the fix, not before: the deployment installs this file, so an
# open range lets Community Cloud upgrade into the breakage.
streamlit>=1.56,<1.63
openpyxl>=3.1
# Server-side figure rendering for the 'every figure as PNG' export on tab 7. The
# per-figure camera button needs nothing -- it renders in the browser -- so a
# deployment where kaleido fails loses the zip and keeps everything else.
kaleido>=1.0
